## Existing APIs reused

1. Login the local BrandAdmin and verify `GET /api/v1/identity/auth/me`.
2. Read `/identity/branches` and public `/identity/branches/active?tenantCode=aicos-cashier-local` to check tenant scope.
3. PUT `/api/v1/identity/branches/{id}` to rename the original branch.
4. POST `/api/v1/identity/branches` for missing branches only.
5. GET `/api/v1/tables/floor-plan?branchId=...` before each branch batch.
6. POST `/api/v1/tables/dining-tables/batch` for missing table codes/areas only.
   Existing table code with a different area/capacity stops provisioning rather
   than overwriting existing data. Each batch creates 12 tables and 3 areas.
7. Read back each branch through the API and logout the setup session.

Requests containing Vietnamese text explicitly used UTF-8 JSON bytes. No new
endpoint, service, migration or schema change was needed. No server code changed.
No DELETE, reset, credential change or ACL modification was performed in this task.
